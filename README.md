# Lista de Compras

Um projeto prático desenvolvido com o objetivo exclusivo de estudar e consolidar os fundamentos de engenharia de software aplicados ao front-end. 

Este repositório serve como ambiente de prática para manipulação do Document Object Model (DOM), escuta de eventos e estruturação de interfaces web.

## 🛠️ Tecnologias Utilizadas

*   **HTML5:** Estruturação semântica da página.
*   **CSS3:** Estilização, layout flexível e aplicação de fontes externas (Google Fonts).
*   **JavaScript (Vanilla):** Lógica de programação, criação dinâmica de elementos e captura de eventos de teclado e mouse.

## ✨ Funcionalidades

*   Adicionar novos itens à lista através do clique no botão.
*   Adicionar itens pressionando a tecla "Enter".
*   Validação para impedir a inserção de itens vazios.
*   Remoção de itens individuais da lista.

## 🚀 Como rodar o projeto localmente

Para testar este projeto no seu próprio computador, siga os passos abaixo:

1.  Clone este repositório usando o terminal:
    ```bash
    git clone https://github.com/axnder/shopping-list.git
    ```
2.  Navegue até a pasta do projeto:
    ```bash
    cd shopping list
    ```
3.  Abra o arquivo `index.html` diretamente no seu navegador de preferência (dando um duplo clique no arquivo).
    *   *Dica:* Se estiver utilizando o Visual Studio Code, você também pode abrir a pasta no editor e usar a extensão "Live Server" para rodar o projeto em tempo real.
